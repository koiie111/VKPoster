# Как подключить TikTok

Откройте «Каналы» → «Подключить канал» → TikTok и войдите через TikTok Login. Разрешите доступ к профилю, публикации и списку видео. Сервис сохранит доступ в зашифрованном виде; пароль TikTok ему не нужен.

Если кнопки TikTok нет, сеть пока не включена администратором. Для отправки роликов администратор должен настроить приложение TikTok, S3 и подтверждённый HTTPS адрес медиа. До аудита приложения TikTok может разрешать только приватные видео.

В редакторе короткого видео выберите доступную для аккаунта видимость, настройки комментариев, дуэтов и стежков, отметьте коммерческий контент и подтвердите права на музыку. Если TikTok изменит доступные параметры до выхода поста, публикация остановится с объяснением. Суточный лимит TikTok зависит от аккаунта; когда он исчерпан, сервис отложит попытку.
