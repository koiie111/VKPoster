# Референсы и выводы (этап 21, часть A)

Только выводы и собственные схемы; чужие материалы не копируются. Ориентиры: Buffer, Later, Hootsuite, SMMplanner, Publer, Metricool.

## Что берём
- **Редактор (Buffer, Publer):** один текст, переключатели соцсетей сверху, справа живое превью под каждую сеть. Счётчик символов показывает лимит самой строгой выбранной сети.
- **Календарь (Later, Metricool):** неделя по умолчанию, режимы «месяц / неделя / список». Пост в календаре — компактная плашка с цветной точкой сети и временем. Перенос мышью и быстрое создание кликом по свободной ячейке.
- **Онбординг (Buffer, Later):** 3 шага: подключить канал → создать первый пост → выбрать время. Пустые экраны ведут к следующему шагу, а не просто сообщают «ничего нет».
- **Статусы (Hootsuite):** у поста всегда виден статус и причина сбоя с понятным действием («замените фото и повторите»).
- **Плотность (SMMplanner, Hootsuite):** для тех, кто ведёт много каналов, нужен компактный список, поэтому дизайн-система должна допускать плотный режим.

## Чего избегаем
- Перегруженная панель Hootsuite: много вкладок на первом экране.
- Технические сообщения об ошибках API в интерфейсе.
- Время без часового пояса.

## Вывод для трёх вариантов
- A «Индиго» — воздух и мягкость (как Buffer).
- B «Коралл» — тепло и крупные элементы (как Later).
- C «Бирюза» — плотность и границы (как Hootsuite, Metricool).
Шрифт во всех вариантах Inter (OFL, self-hosted); выбор шрифта можно обсудить отдельно.
