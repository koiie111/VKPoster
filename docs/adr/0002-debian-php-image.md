# 0002. Образ PHP на Debian (bookworm), а не Alpine

- Статус: принято
- Дата: 2026-10-04

## Контекст
План предполагал `php:8.3-fpm-alpine`. Tailwind CSS standalone CLI (v3.4.x) публикуется только как glibc-бинарник, musl-сборок у этой ветки нет. Бинарник нужен в dev- и prod-образах (этап 21).

## Решение
Базовый образ `php:8.3-fpm-bookworm`. Tailwind скачивается по фиксированной версии с проверкой SHA-256 (отдельно для amd64 и arm64). Nginx и остальные сервисы остаются на alpine-образах.

## Рассмотренные варианты
- Alpine + `gcompat`: хрупко для бинарника, собранного Bun.
- Tailwind v4 (есть musl-сборки): другая конфигурация (CSS-first), расходится с планом (`tailwind.config.js`).
- Node в образе: запрещено планом (без Node).

## Последствия
Образ больше (~+300 МБ). Пакеты ставятся через `apt`. Версию Tailwind и хэши меняем только вместе в `docker/php/Dockerfile`.
