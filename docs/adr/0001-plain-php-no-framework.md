# 0001. Чистый PHP без фреймворков

- Статус: принято
- Дата: 2026-10-04

## Контекст
Проект переписывается с нуля. Владелец решил писать на чистом PHP, без Laravel/Symfony/Slim; нужен предсказуемый, небольшой код, который понятен автору и агентам.

## Решение
Собственный небольшой каркас в `src/Kernel` (роутер, DI-контейнер, middleware, БД, сессии, безопасность, очередь). Разрешены только узкие библиотеки Composer из белого списка (`docs/plans/ENGINEERING_RULES.md` §2); всё остальное требует отдельного ADR.

## Рассмотренные варианты
- Laravel/Symfony: быстрее старт, но решение владельца — без фреймворков.
- Slim + набор пакетов: тоже фреймворк по сути, потеря контроля над безопасностью по умолчанию.

## Последствия
Безопасность (CSRF, сессии, CSP, rate limit) пишем и тестируем сами: этап 01 и чек-лист безопасности обязательны. Больше кода в ядре, зато нет скрытой магии и лишних зависимостей.
