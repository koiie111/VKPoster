# 0026. ИИ-ассистент: цепочка моделей с суточными лимитами

- Статус: принято, требует живой проверки владельцем с ключом Tokenator
- Дата: 2026-10-25

## Контекст
ADR 0016 оставил в техдолге «fallback между провайдерами». Владелец хочет сначала тратить бесплатные модели шлюза Tokenator (у каждой свой суточный запас запросов, токены пакета не расходуются) и только потом платные токены. Tokenator OpenAI-совместим (`https://api.tokenator.cloud/v1`), отдельный клиент не нужен.

## Решения
1. **Шаг цепочки** (`ai_chain_steps`): провайдер из `ai_providers` (ключ и адрес не дублируются), необязательная модель, лимит запросов в сутки со сдвигом начала суток от UTC, пауза после ошибки (0 = по причине), «списывать кредиты пользователя», список обслуживаемых действий (пусто = все), порядок, флаг включения. Всё меняется в админке без выкладки. Ключей в таблице нет. Пустая цепочка = один провайдер по умолчанию, как раньше.
2. **Счётчики в Redis, не в БД**: быстрый атомарный `INCR` в Lua с проверкой лимита и «отдыха» шага. Redis недоступен: шаг считается недоступным, платную модель не бьём наугад (так же ведёт себя лимит запросов в минуту).
3. **Лимит в запросах, не в токенах**: у бесплатных моделей Tokenator главным ограничением служат запросы (20–60 в сутки на модель), токены считает сам шлюз. Расхождение часов с шлюзом закрывает ответ 429: шаг отдыхает 15 минут, запрос идёт дальше.
4. **Ошибка = следующий шаг**, кроме `refused` (проблема в тексте, а не в модели). Ошибки пишутся в `ai_usage` без списания кредитов. Кредиты пользователя по умолчанию списываются за любой ответ (цена не зависит от источника), но флаг шага позволяет сделать его ответы бесплатными.
5. **Своя модель пространства цепочку обходит** (кредиты не списываются, как и раньше).
6. **Пресет `tokenator`** в `LlmCatalog`; модель шага может быть любой строкой, поэтому смена списка бесплатных моделей не требует выкладки.

## Не проверено
Живые вызовы Tokenator: формат ответа 429 при исчерпанной квоте free-моделей и часовой пояс обновления суточного запаса (проверено только на фикстурах). Тексты пользователей уходят третьей стороне: нужен пункт в политике конфиденциальности (владелец).

## Не вошло
Лимит в токенах, локальная модель на сервере koiie (CPU без GPU, возможна как последний шаг через `custom-` провайдера за https).
