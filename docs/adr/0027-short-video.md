# ADR 0027 — Публикация коротких видео

**Статус:** предложено 2026-11-05; разрешения приложений и поведение живых API ещё не проверены.

## Решения владельца

Делаем TikTok, YouTube Shorts, Instagram Reels и VK Клипы. Владелец уточнил: VK Клипы остаются недоступными до появления официального API; обычное видео VK не подменяет Клип. Функция доступна на всех тарифах. Начальные общие пределы файла — 1 ГиБ, длительности — 180 секунд; по уточнению владельца 2026-11-05 это настройки в админке, а не жёсткие константы. Предлагаемые лимиты по действующей шкале медиатеки: Free — 250 МиБ на файл и 2 видео в месяц, Старт — 500 МиБ и 10, Про — 1 ГиБ и 60, Агентство — 1 ГиБ и 300. Ограничение общего места медиатеки продолжает действовать. Тарифные лимиты хранятся в каталоге тарифов и редактируются в админке владельца.

## Архитектура

Тип поста `short_video` содержит ровно один исходный ролик и необязательную обложку. Поля платформ проверяют возможности адаптеров. Загрузка, перекодирование и ожидание сети идут в отдельной очереди `video`; обычная очередь `publish` не ждёт длительную передачу файла. ID внешней операции сохраняется до следующего побочного эффекта. Неизвестный результат сверяется с сетью или требует ручного действия без автоматического дубля. URL для загрузки, выданные сетью, проверяются по разрешённым хостам и SSRF-правилам; публичные ссылки на свои файлы подписываются. Вариант видео — MP4 с H.264/AAC и удалёнными метаданными; `ffprobe` проверяет ограничения каждой сети. Перед сборкой частей проверяются лимит файла и свободное место пространства.

Общий потолок хранится в `app_settings` (`limits.short_video_file_mib`, `limits.short_video_duration_seconds`), начальные значения 1024 МиБ / 180 секунд. Владелец меняет их в `/admin/settings`; тариф и требования сети могут быть строже. Изменение действует для новых и повторно проверяемых публикаций, а не меняет уже отправленные ролики.

Для сетей, недоступных с российского Core, используются маршруты `EgressRoutes` из ADR 0022 и операторский прокси/туннель в Германии. TikTok, YouTube и Instagram получают отдельные провайдеры egress, без глобального VPN и обходного HTTP-клиента. Фактический выходной IP и доступность немецкого узла проверяет владелец на живом стенде; код и тесты не доказывают географию.

## Условия выпуска

Автотесты не обращаются к живым API. Реальные аккаунты, права, публичный TikTok после аудита и квоты YouTube требуют проверки владельца. На текущем этапе DoD охватывает TikTok, YouTube Shorts и Instagram Reels; VK Клипы исключены по решению владельца до появления официального API. Подмена VK Клипов обычным видео запрещена.
