# Этап 09 — MAX

**Зависимости:** 07 · **Ветка:** `stage-09-max`

## Цель
Постинг в каналы и чаты мессенджера MAX.

## Важно
С октября 2025 года ботов MAX регистрируют только **верифицированные юрлица РФ**. Поддерживаем два режима:
1. **Общий бот сервиса** (если у владельца есть юрлицо и верифицированный бот) — как в Telegram, с кодом подключения.
2. **Свой бот клиента** — клиент-юрлицо вводит токен своего бота.

## Задачи
- [x] Исследование актуального API на dev.max.ru (результат — [ADR 0007](../../adr/0007-max-bot-api.md)): базовый URL (`https://platform-api2.max.ru` на момент планирования), авторизация заголовком `Authorization`, `POST /messages?chat_id=`, `POST /uploads` (типы image/video/file), форматирование (`format: markdown|html`), кнопки (inline keyboard, link), закрепление, удаление, редактирование, вебхуки (`POST /subscriptions`), получение чатов, где бот участник, и прав бота.
- [x] Клиент MAX API на HttpClient, классификация ошибок, лимит 2 сообщения в секунду на чат (Redis-семафор), повтор при «вложение ещё не обработано» (загрузка видео асинхронна — ждать готовности с backoff).
- [x] Коннектор: режим общего бота (код подключения через вебхук) и режим своего бота (ввод токена и ссылки или номера канала; списка чатов в MAX нет, см. ADR 0007).
- [x] Адаптер: текст (до 4000 символов), фото, видео, файлы, кнопки-ссылки, `notify=false` для тихой отправки, отключение превью, закрепление, удаление, редактирование.
- [x] Health check.
- [x] Capabilities и превью в редакторе (превью `max` уже было в редакторе, лимиты и опции берутся из `Capabilities`).

## Тесты
Фикстуры, загрузка медиа с ожиданием обработки, ошибки авторизации, лимиты.

## Проверка владельцем
1. Есть ли верифицированное юрлицо и бот MAX? Если да — вписать `MAX_BOT_TOKEN`. Если нет — проверяем только режим «свой бот» на чужом тестовом токене или откладываем живую проверку (этап всё равно мержится на фикстурах, в PROGRESS ставится пометка «MAX: живой тест отложен»).
2. Опубликовать в тестовый канал текст, фото, видео, кнопку. Всё ок?

## DoD
Тесты на фикстурах зелёные; живая проверка выполнена или явно отложена владельцем.
