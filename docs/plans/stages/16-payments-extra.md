# Этап 16 — Остальные платёжки, рефералка, промокоды, пакеты

**Зависимости:** 10 · **Ветка:** `stage-16-payments-extra`

## Задачи
- [ ] **CloudPayments**: виджет оплаты, проверка `Content-HMAC` (HMAC-SHA256 от тела, ключ API Secret) для уведомлений Check/Pay/Fail/Recurrent, рекуррентные подписки через API или токен карты, чеки (CloudKassir).
- [ ] **Stripe** (официальный SDK): Checkout Session в режиме `subscription`, Customer Portal, вебхуки (`Stripe-Signature`, допуск по времени 5 мин), синхронизация `customer.subscription.*`, `invoice.paid/payment_failed`. Валюта USD/EUR, отдельные цены в `plan_prices`.
- [ ] **Paddle Billing**: Paddle.js checkout, вебхуки (`Paddle-Signature`, HMAC-SHA256 `ts:body`), синхронизация подписки. Paddle — Merchant of Record (налоги на нём).
- [ ] **Крипта**: провайдер выбирает владелец (варианты: CryptoCloud, Cryptomus, NOWPayments, Heleket — ADR по комиссиям, KYC, доступности); инвойс на сумму за период, вебхук с подписью, учёт недоплаты и переплаты, без автопродления.
- [ ] **Telegram Stars**: оплата в боте уведомлений: `sendInvoice`/`createInvoiceLink` (`currency=XTR`, при возможности `subscription_period=2592000`), обработка `pre_checkout_query` (проверка счёта, ответ в течение 10 с), `successful_payment` → активация, `refundStarPayment` для возвратов. Цены в звёздах в `plan_prices`.
- [ ] Выбор способа оплаты на странице тарифов: показываем доступные по стране и валюте (РФ → ЮKassa / Т-Банк / CloudPayments; иностранные карты → Stripe / Paddle; плюс крипта и Stars).
- [ ] **Промокоды**: процент, сумма, бесплатные дни; ограничения (тарифы, первый платёж, лимит активаций, срок, один на пользователя); админка.
- [ ] **Реферальная программа**: реф-ссылка (cookie 30 дней, атрибуция при регистрации), 20% с оплат приглашённых → ledger-баланс; оплата тарифа балансом; заявки на вывод для партнёров (ручная обработка в админке); защита от самоприглашения (тот же платёжный отпечаток, IP или устройство → отклонение).
- [ ] **Пакеты**: +каналы, +участники, +хранилище, AI-кредиты (подготовка под этап 17) — как позиции счёта.

## Тесты
Подписи вебхуков каждого провайдера (валидная, невалидная, старый timestamp); идемпотентность; Stars: `pre_checkout_query` для несуществующего или чужого счёта → отказ; промокод сверх лимита; рефералка: самоприглашение, возврат платежа → сторно бонуса в ledger.

## Проверка владельцем
1. Какие провайдеры реально подключаем сейчас (для Stripe и Paddle нужно иностранное юрлицо; для крипты — выбор провайдера)? Вписать тестовые ключи.
2. Тестовая оплата через каждого подключённого провайдера. Ок?
3. Условия рефералки (20%, вывод) — подтвердить.

## DoD
