# Этап 14 — Согласование, комментарии, гостевые ссылки

**Зависимости:** 04, 07 · **Ветка:** `stage-14-approvals`

## Задачи
- [ ] Настройка workspace: «посты авторов требуют согласования» (вкл/выкл), кто согласует (admin/editor или конкретные люди).
- [ ] Статусы: `draft → pending_approval → approved → scheduled` / `changes_requested`; при изменении одобренного поста — снова на согласование.
- [ ] Комментарии к посту (треды, упоминания `@участник` с уведомлением), история версий поста с diff текста.
- [ ] **Гостевая ссылка для клиента** (тариф Про и выше): подписанная ссылка на набор постов или период календаря; клиент без регистрации видит превью, может одобрить или оставить комментарий; ссылка с TTL, отзываемая, опционально с PIN-кодом; rate limit; white-label (логотип и цвета workspace) — для тарифа «Агентство».
- [ ] Уведомления о смене статусов (email + TG).
- [ ] Роль `client` (из этапа 04): видит только назначенные каналы и посты.

## Тесты
Автор не может обойти согласование (прямой POST на schedule → 403); гостевая ссылка: подделка, истёкшая, отозванная, PIN-перебор; клиент не видит чужие каналы; изменение одобренного поста сбрасывает статус.

## Проверка владельцем
Не требуется.

## DoD
Тесты зелёные.
