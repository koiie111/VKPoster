# Этап 13 — Слоты, повторы, триггеры, кросспостинг, RSS, массовый импорт

**Зависимости:** 07, 10 (лимиты) · **Ветка:** `stage-13-advanced-scheduling`

## Задачи
- [ ] **Слоты (очередь)**: расписание на канал или группу каналов (дни недели × время); кнопка «В очередь» ставит пост в ближайший свободный слот; перестановка очереди; пауза очереди.
- [ ] **Повторяющиеся посты**: правило (каждый день / по дням недели / каждые N дней / ежемесячно), дата окончания, лимит повторов. **Вечнозелёный пул**: набор постов, публикуемых по кругу в слоты, с минимальным интервалом повтора одного поста.
- [ ] **Триггеры** (события → действия):
  - события: пост опубликован, время X, публикация упала;
  - действия: удалить через N, закрепить или открепить в момент X, опубликовать следующий пост цепочки, поставить на паузу или снять с паузы очередь канала, уведомить.
  - UI «если → то» на странице поста и канала.
- [ ] **Автокросспостинг TG → VK/MAX(/IG)**: бот получает `channel_post` из канала-источника; правило: каналы-получатели, фильтры (хэштег-включение/исключение, пересланные посты пропускать), преобразования (убрать подпись канала, добавить хвост, заменить ссылки), задержка, режим «в черновики на согласование» или «сразу». Альбомы TG (`media_group_id`) собираются в один пост (буфер 3–5 с). Редактирование и удаление в источнике — опционально синхронизируются.
- [ ] **RSS/Atom → посты**: опрос по расписанию (через SsrfGuard, `ETag`/`If-Modified-Since`), шаблон поста из полей (title, link, summary, первая картинка), дедупликация по guid, режим «черновик» или «в очередь».
- [ ] **Массовый импорт CSV/XLSX**: шаблон файла (дата, время, каналы, текст, ссылки на медиа), предпросмотр с ошибками по строкам, импорт в черновики или сразу в расписание.
- [ ] Лимиты по тарифу (количество правил кросспостинга, RSS-лент).

## Тесты
Расчёт ближайшего слота с часовыми поясами; повтор с переходом через конец месяца (31-е число); дедупликация RSS и кросспостинга (повторная доставка апдейта TG); сборка альбома; триггер срабатывает ровно один раз; CSV с инъекцией формул (`=cmd|…`) — экранируется при экспорте и не исполняется.

## Проверка владельцем
Не требуется (используется TG из этапа 06 на фикстурах); по желанию — проверить кросспостинг вживую.

## DoD
Все механики покрыты тестами, UI работает.
