# Этап 08 — VK

**Зависимости:** 07, 03 · **Ветка:** `stage-08-vk`

## Цель
Постинг в сообщества VK с теми же гарантиями, что и в TG.

## Задачи
- [ ] **Сначала исследование** (результат — ADR `docs/adr/NNNN-vk-auth.md`): сверить на dev.vk.com актуальный способ получить токен с правами `wall, photos, video, docs, groups, offline` (VK ID OAuth 2.1 с refresh-токеном, или ключ доступа сообщества, или оба: какие методы с каким токеном работают). Если нужна модерация доступа к стене — вынести владельцу.
- [ ] Свой тонкий клиент VK API (v5.199+ — проверить актуальную), без устаревшего `vkcom/vk-php-sdk` (если он не поддерживается — ADR), обработка `error_code` (5 — auth, 6/9 — rate limit, 14 — captcha → permanent с понятным текстом, 15/214 — нет прав, 100 — параметры).
- [ ] Коннектор: «Подключить VK» → OAuth с нужными правами → список сообществ, где пользователь admin/editor (`groups.get` filter=admin,editor) → выбор нескольких → каналы. Хранение и обновление refresh-токена (с блокировкой от гонок).
- [ ] Публикация `wall.post` (`owner_id=-group_id`, `from_group=1`): текст, фото (`photos.getWallUploadServer` → upload → `saveWallPhoto`), видео (`video.save` → upload), документы, опросы (`polls.create`), подпись (`signed`), отключение комментариев, ссылки-превью.
- [ ] Первый комментарий (`wall.createComment` от имени сообщества), закрепление (`wall.pin`), удаление (`wall.delete`), редактирование (`wall.edit`).
- [ ] Проверка исхода `unknown`: `wall.get` последних N постов и сравнение по нашей метке (хэш текста + время).
- [ ] Rate limit: не более 3 запросов в секунду на токен (Redis-семафор), суточный лимит постов на сообщество → понятная ошибка до планирования.
- [ ] Health check: токен жив, пользователь всё ещё админ.
- [ ] Capabilities VK в превью редактора (длина текста, 10 вложений, нет кнопок).

## Тесты
Фикстуры всех вызовов, загрузка фото (мульти-шаг), обновление токена при истечении, ошибки 5/6/14/214, `unknown` → поиск поста.

## Проверка владельцем
1. Создать VK ID приложение (или переиспользовать из этапа 03), выдать права на стену (если требуется заявка — подать) и вписать ключи в `.env`.
2. Подключить тестовое сообщество, опубликовать: текст, 5 фото, видео, пост с первым комментарием и закреплением, пост с удалением через N минут. Всё корректно?

## DoD
Публикации в VK работают вживую; ADR по авторизации записан.
