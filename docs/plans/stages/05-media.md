# Этап 05 — Медиатека

**Зависимости:** 04 · **Ветка:** `stage-05-media`

## Цель
Безопасная загрузка и хранение фото/видео/документов, подготовка вариантов под каждую соцсеть, водяные знаки.

## БД
`media`, `media_folders`, `watermarks`.

## Задачи
- [ ] `Storage` за интерфейсом (Flysystem): `local` (`storage/media`) и `s3` (minio в dev, профиль `s3`). Ключи вида `ws/{workspaceId}/{yyyy}/{mm}/{ulid}.{ext}`.
- [ ] Загрузка: drag&drop, несколько файлов, прогресс (htmx/fetch), лимит размера по тарифу (пока из конфига), квота хранилища workspace.
- [ ] Проверки: MIME по содержимому (`finfo`), белый список (jpeg, png, webp, gif, mp4, mov, pdf), расширение по MIME (не по имени), размеры изображения ≤ 10000×10000 (защита от decompression bomb), SVG запрещён.
- [ ] Изображения: пересжатие через Imagick/GD (снимает EXIF, кроме ориентации — применяем её), превью 320px, хэш SHA-256 для дедупликации.
- [ ] Видео: `ffprobe` (добавить ffmpeg в образ) для длительности, разрешения и кодека; превью-кадр; проверка требований платформ (`capabilities`).
- [ ] Варианты под платформы (по запросу при публикации, с кэшированием): кадрирование 1:1 / 4:5 / 1.91:1 / 9:16, ограничение по размеру и весу.
- [ ] Водяной знак: загрузка логотипа (PNG), позиция (9 точек), прозрачность, отступ, масштаб; применение к варианту при публикации; предпросмотр.
- [ ] Раздача: только через `/media/{id}/{variant}` с проверкой доступа или подписанный URL с TTL (для отдачи соцсетям, которые сами скачивают по URL, например Instagram); `Content-Disposition` и `X-Content-Type-Options: nosniff`.
- [ ] Загрузка по ссылке (URL → медиа) через SsrfGuard, лимит размера и времени.
- [ ] UI медиатеки: сетка, папки, поиск, удаление (с проверкой использования в запланированных постах).

## Тесты
Файл с поддельным расширением (PHP под .jpg) → отклонён; polyglot-файл после пересжатия не содержит исходных байтов; огромные размеры → отказ; квота; подписанный URL истёк или подделан → 403; чужой workspace → 404; SSRF при загрузке по ссылке.

## Проверка владельцем
Не требуется.

## DoD
Тесты зелёные; файлы физически не доступны через nginx напрямую.
