# Этап 15 — Аналитика

**Зависимости:** 08, 09 · **Ветка:** `stage-15-analytics`

## Задачи
- [x] Интерфейс `StatsFetcher` на платформу; сбор метрик по публикациям: через 1 ч, 6 ч, 24 ч, 3 дня, 7 дней (снапшоты), затем раз в неделю до 30 дней.
  - VK: `wall.getById` (views, likes, reposts, comments), `stats.getPostReach` (если доступно по правам).
  - TG: просмотры поста ботом напрямую не получить — проверить доступные варианты (реакции через апдейты `message_reaction_count`, если бот админ; просмотры — пометить «недоступно» или ADR о MTProto-клиенте как отдельной опции). Подписчики: `getChatMemberCount`.
  - MAX: что отдаёт `Message` (статистика поста канала) — по ADR этапа 09.
  - IG: Insights API (если этап 12 сделан).
- [x] Снапшоты подписчиков каналов раз в сутки.
- [x] Дашборд: сводка по периоду (публикации, охват, вовлечённость, ER), график по дням, топ-постов, сравнение каналов, разбивка по платформам. Графики — лёгкая библиотека (Chart.js из vendor, ADR).
- [x] **«Лучшее время»**: тепловая карта день недели × час по средней вовлечённости своих постов (минимум N постов, иначе подсказка «мало данных»); подсказка в планировщике и в настройке слотов.
- [x] Экспорт CSV (с защитой от формул) и PDF-отчёт (HTML → PDF через headless Chromium в отдельном контейнере или wkhtmltopdf — ADR); отчёт клиенту по гостевой ссылке (этап 14).
- [x] Хранение по тарифу (7 дней / 30 дней / 1 год).
- [x] Сбор статистики через очередь с учётом rate limit платформ.
