# Этап 11 — Лендинг, юридические страницы, админка → MVP

**Зависимости:** 08, 09, 10 · **Ветка:** `stage-11-landing-admin-mvp`

## Цель
Продукт готов к первым пользователям.

## Задачи
- [x] Лендинг (в стиле дизайн-системы, с иллюстрациями и скриншотами реального интерфейса) (картинка продукта собрана из тех же компонентов с демо-данными): оффер, поддерживаемые сети, ключевые функции, тарифы (из БД), FAQ, CTA «Попробовать 14 дней бесплатно». Быстрый (без тяжёлого JS), SEO-мета, Open Graph, `sitemap.xml`, `robots.txt`.
- [x] Шаблоны юридических страниц (заполняет владелец): публичная оферта, политика обработки ПДн (152-ФЗ), политика cookies, реквизиты. Версионирование документов, повторное согласие при изменении.
- [x] Баннер cookies (только необходимые по умолчанию; аналитика — после согласия).
- [x] Онбординг после регистрации: 3 шага (подключить канал → создать пост → запланировать) + пустые состояния со ссылками на помощь.
- [x] База знаний (статичные markdown-страницы → HTML): как подключить TG/VK/MAX, частые ошибки.
- [x] **Базовая админ-панель** `/admin`; полная версия с бизнес-дашбордом делается на этапе 20 сразу после этого. Доступ только `is_superadmin` + обязательная 2FA + отдельный rate limit. Разделы: пользователи (поиск, блокировка, вход под пользователем с записью в аудит и баннером «вы вошли как»), workspace, подписки и платежи (ручное продление или возврат), тарифы и цены, промокоды (заготовка), очередь и failed jobs (повтор), состояние каналов по платформам, feature-флаги платформ.
- [x] Страница статуса платформ (если VK/TG/MAX API лежит — баннер в приложении).
- [x] Обратная связь: форма «Сообщить о проблеме» → письмо в поддержку с контекстом (без секретов).
- [x] Prod-сборка: `compose.prod.yaml` (без mailpit и dev-инструментов), инструкция по деплою в `docs/deploy.md` (детальная — на этапе 19).

## Тесты
Админка недоступна обычному пользователю (403/404) и суперадмину без 2FA; impersonation пишется в аудит и не даёт доступ к биллингу владельца; юридические страницы отдаются.

## Проверка владельцем
1. Пройти путь нового пользователя с лендинга до первой публикации. Где непонятно?
2. Заполнить тексты оферты и политики ПДн (или дать реквизиты — агент подготовит шаблон для юриста).
3. Готовы запускать MVP? Нужен ли закрытый бета-доступ по инвайтам?

## DoD
Владелец подтвердил готовность MVP. Тег `v0.1.0`.
